# Agent Office: архив / TODO

Статус: **отложено, не используется** (13 октября 2026).

Прототип интерфейса в `office/` и серверный код в `bot/codex_channel.py` и
`bot/office_data.py` сохранены в репозитории для дальнейшей работы. Их наличие
не означает готовность функции. Текущий релиз BotParser не собирает Office,
не показывает вкладку Codex в Telegram Mini App и не регистрирует API маршруты
канала. Nginx отвечает `410 Gone` на старые ссылки и адреса API.

## Что требует доработки

- Определить, нужен ли Agent Office как отдельная Mini App, раздел существующей
  Mini App или самостоятельный сайт. До решения не добавлять второй запуск в Telegram.
- Согласовать сценарии и данные: какие действия пользователь запускает, какие
  события видит и как понимает состояние задания, когда Mac worker недоступен.
- Пересмотреть авторизацию и прямые ссылки: вход из Telegram, срок сессии,
  список доступа и поведение при открытии вне Telegram.
- Проверить устойчивость канала, безопасность трасс, хранение, очистку данных
  и поведение при недоступности Mac или MinIO.
- Провести проверку интерфейса на реальных данных и согласовать выпуск.

## Возврат к работе

Сначала утвердить сценарий и доступ, затем обновить UI и тесты. После этого
отдельным изменением вернуть сборку `office/`, маршруты Nginx и API, включить
Mac worker и проверить весь путь через Telegram. До такого решения не запускать
`factory:office-worker` и не использовать сохранённые настройки канала.
